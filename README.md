# Customer Churn Analysis

## 📌 Project Overview

This project analyzes customer churn data to identify patterns, customer segments, and factors associated with customer attrition.

The project follows a complete data analytics workflow, starting from **SQL data extraction and Python integration**, followed by **data cleaning, feature engineering, exploratory data analysis (EDA), and data visualization**.

The objective is to transform raw customer data into meaningful insights that can help understand customer churn and support data-driven decision-making.

---

## 🎯 Project Objectives

* Connect and retrieve data from a SQL database using Python.
* Clean and validate raw customer data.
* Handle missing/null values and inconsistent data types.
* Engineer new features and calculated columns.
* Analyze customer behavior and churn patterns.
* Perform exploratory data analysis using aggregations and pivot tables.
* Visualize important trends and relationships using Python visualization libraries.

---

## 🔄 Project Workflow

### 1. SQL Database Connection

Connected the SQL database to Python using `sqlite3` and established the data extraction workflow.

### 2. Data Import

Used SQL queries with Pandas and `sqlite3` to retrieve the required datasets directly into Pandas DataFrames.

### 3. Data Cleaning

Performed data preparation and quality checks, including:

* Checking and correcting data types
* Renaming columns
* Selecting relevant columns
* Checking data quality and consistency
* Identifying missing/null values
* Handling missing values
* Filtering unnecessary records

### 4. Feature Engineering

Created analytical features from the existing customer data using Pandas and NumPy.

This included:

* Creating calculated columns
* Transforming existing variables
* Applying conditional logic
* Creating filtered datasets
* Deriving customer-level analytical metrics

### 5. Exploratory Data Analysis

Performed EDA to understand customer characteristics and churn behavior using:

* Aggregations
* `GROUP BY`
* Pivot tables
* Filtering
* Summary statistics
* Category-wise analysis

The analysis was used to identify patterns across different customer segments and churn categories.

### 6. Data Visualization

Created visualizations using **Matplotlib and Seaborn** to communicate important patterns and trends.

Visual analysis included comparisons of customer segments, churn behavior, and relevant customer attributes.
